使用手册

本手册按照页面结构编写，从聊天页开始，依次说明加号面板、后台管理和数据管理。所有功能都可以在实际页面中直接找到，遇到不熟悉的项目时查看对应章节即可。

聊天记录、设置和字卡都保存在当前浏览器中，不会上传到服务器。更换设备、清理浏览器数据或使用无痕模式前，请先在「后台管理 → 数据管理」中导出备份。

一、聊天页

聊天页由顶栏、签名栏、消息区和输入栏四部分组成。

1. 顶栏

  • 左侧显示对方昵称，昵称下方是状态气泡、网络和电量信息。网络可能变成 2G，2G 会轻微拖慢回复，并弹出网络提示。
  • 🌙 / ☀️ 用于切换夜间模式和白天模式。夜间模式的按钮和气泡会跟随当前配色，其余界面使用统一的深色方案。
  • 🖥️ 用于切换电脑宽屏布局；在手机上通常不需要开启。
  • ⋯ 进入后台管理，聊天设置、字卡库、音乐管理、数据管理等都在这里。

2. 签名栏

签名栏显示对方的个性签名，并按设定时间自动轮换。播放音乐时，签名栏会临时变成歌词显示区；暂停或关闭播放器后恢复为签名。

3. 消息区

  • 普通文字、图片、语音和各类卡片都按时间顺序排列。
  • 双击某条消息可以引用回复；长按消息或点击鼠标右键可以打开操作菜单，进行引用、复制或删除。
  • 双击对方头像可以触发一次「拍一拍」。
  • 他最新一条消息下方可能出现情绪气泡，表示他此刻的心情；没有显示时，说明当前最后一条消息不是他发的，或情绪尚未刷新。
  • 历史记录很长时，首屏只加载最近约 200 条，顶部会显示「加载更早的 N 条消息」按钮，点击继续加载上一批。

手机端加载

首屏要建立字体、配色和最近约 200 条消息的布局；图片、语音和音乐是滚动到附近或点开时才读取，不会一次全部下载。手机浏览器在后台或省电模式下会限制计时器和网络请求，所以同样的内容可能比电脑多等一会儿。音乐第一次播放要先读取 mp3 文件，文件较大或网络较慢时会显示「加载中…」；打开播放器会先预载当前歌曲，只要还有数据持续到达就不会被判定超时，完全没有新数据超过约 45 秒才提示「加载超时」。历史记录、图片和语音越多，滚动和切换越慢，可以导出备份后清理旧记录，或只清理图片/语音；常用歌曲可以导入本地。

4. 输入栏

  • 输入文字后点击「发送」或按回车键发送。
  • 😄 打开表情面板，可选择 Emoji 或已保存的表情图片。
  • ＋ 打开加号面板，包含图片、通话、红包、礼物、选择、音乐等工具。
  • 💌 让他主动发消息，发送数量由聊天设置中的「回复条数」决定。

二、加号面板

加号面板分为两页，可以左右滑动，也可以点击底部的两个小圆点切换。电脑上可用鼠标滚轮翻页。

第一页

  • 拍照 / 图片：发送相机拍摄或相册中的图片。图片过大时会自动压缩。
  • 语音通话：发起通话；对方可能接听、拒接或无人接听，结果会记录在聊天中。通话记录带电话图标，未接来电和已挂断使用红色图标，正常结束使用主题色图标，已取消为灰色图标。
  • 位置：先发送「你在哪呀？」，随后由对方回复一个位置卡片。
  • 红包 / 转账：输入金额和备注，按提示完成支付密码验证后发送。金额支持小数；转账备注会显示在卡片上。
  • 对方发来的金额：红包普通金额约一半带小数，转账普通金额为整数；特殊金额包括 50、88、99、100、200、500、520、999、1000、1314、2000、5200、8888、9999 等，越大越少见。
  • 礼物：按价位和类型筛选礼物，选择后发送；对方收到的礼物需要拆开。
  • 互动：发送摸摸头、抱抱、贴贴等互动请求，对方会给出对应回应。

通话的五种结果

  • 他打给你，铃声响完你未接：记录为「未接来电」。
  • 你打给他，铃声响完他未接：记录为「对方未接来电」。
  • 你打给他，他未接就挂断：记录为「对方已挂断」。
  • 他打给你，你未接就挂断：记录为「已挂断」。
  • 接通后结束：记录为「通话结束 时长」。

通话记录之后，他通常会按情况回复一句。未接和挂断约 60% 使用内置句子、40% 抽取字卡；通话结束和已取消约 50% / 50%。字卡库为空时使用内置句子；内置句子约 42% 在末尾带 emoji。通话结果也会临时提高对应情绪权重：他打来但你没接到时偏等待、不安；你打给他但他没接到时偏抱歉、心虚；通话结束偏开心、亲密。

第二页

  • 选择：创建一张选择卡。默认两个选项，可以继续添加；设置「从中选几个」后发送。对方会先显示「思考中」，再回复「我选……」。
  • 音乐：打开播放器，不会自动播放。点击播放按钮播放上一次听的歌曲，点击播放器上的歌名进入歌单。播放条顶部中间的小拉条可以收起/展开播放器，收起后歌曲继续播放，不占聊天空间。
  • 录音：仅在浏览器支持麦克风时显示。按住录音、松开发送；首次使用需要允许麦克风权限。

三、后台管理

点击聊天页右上角的「⋯」进入后台管理。后台包含以下入口：

  • 聊天设置：昵称、头像、壁纸、回复节奏、时间格式、主题与配色等。
  • 聊天记录：查看历史消息、按条件筛选和清理。
  • 自定义回复：管理文字字卡、Emoji、表情图片和标签。
  • 数据管理：查看占用空间、导出、导入和清理数据。
  • 音乐管理：排序、隐藏、删除曲目，导入音频和歌词。
  • 使用手册：即当前页面。

各页面左上角的「‹」返回上一级；聊天设置页如有未保存的修改，返回时会提示保存或放弃。

四、聊天设置

1. 基本信息

  • 昵称：分别设置你的昵称和对方的昵称，会显示在消息、拍一拍和系统提示中。
  • 头像与壁纸：选择图片后可裁剪为方形或圆形；壁纸不需要裁剪。对方未上传头像时，默认显示像素爱心，并跟随当前配色。
  • 恢复默认：「恢复默认头像」会清除双方的自定义头像；「恢复默认壁纸」会清除聊天背景。两项都需要点击保存后生效。
  • 拍一拍：设置你拍对方时使用的动作和附加文字，下方会实时显示预览。

2. 回复节奏

  • 回复延迟：控制对方回复前的等待时间。实际延迟会在 0 到这个时间之间随机取值。
  • 回复条数：控制一次回复发送几条消息。
  • 签名刷新：控制个性签名自动轮换的间隔，最短 15 分钟。
  • 自动回复：开启后，在设定的无互动时间后主动发来消息；设置为 0 表示关闭。

3. 显示与外观

  • 时间格式：选择 12 小时制或 24 小时制，并可选择是否显示秒。
  • 界面配色：分为单色、撞色、科技和渐变四组。点击配色会立即预览，保存后生效。
  • 显示「正在输入」：关闭后，对方回复前不再显示输入提示。
  • 消息音效：控制发送和接收消息时的提示音。
  • 显示已读 / 未读：开启后，双方消息时间旁都会显示「未读 / 已读」；他准备回复时你的消息变为已读，离线期间保持未读；他的消息在后台保持未读，回到前台后变已读。
  • 手机通知：需要浏览器通知权限；页面在后台时会通知新消息，完全关闭页面后不会推送。
  • 情绪气泡：控制他最后一条消息下方是否显示心情气泡，默认开启。
  • 开场动画染色：控制启动页是否跟随当前界面配色。开启时随配色变化；关闭时固定使用默认绿色。
  • 图标色调：可选择原色、柔和或跟随配色。

修改完成后请点击右上角保存。部分外观设置需要保存后才会应用到所有页面。

五、自定义回复

「自定义回复」用于管理对方聊天时可能使用的文字和表情。页面分为三个标签：

  • 字卡：纯文字回复，可以按标签分类。
  • Emoji：单个或多个表情，会以一定概率附加在回复末尾。
  • 表情包：图片表情，发送时会以图片消息出现。

常用操作

  • 可以直接新增，也可以批量粘贴多行文字。
  • 「📥 导入」只追加文字字卡，不会覆盖现有字卡；有分类会自动复用或新建标签，重复文字会跳过。支持 JSON、TXT、CSV；TXT 可写「分类<Tab>内容」或「分类|内容」，CSV 默认分类,内容。
  • 「查重」会找出重复的文字字卡，并可选择保留最早的一条。
  • 「批量管理」用于多选、移动标签或删除。
  • 标签用于区分不同语气或场景，例如日常、亲密、吃醋。对方抽到带特定标签的卡片时，情绪会短暂受到影响。

字卡库为空时，会弹出提示并可直接前往「自定义回复」添加字卡，不会发送空白消息。互动和推荐歌曲采用「内置回复 + 字卡」的混合模式：互动五五开，推荐歌曲约 40% 内置、60% 字卡。具体比例见第八节。

六、音乐

1. 播放器

  • 点击加号面板中的「音乐」只打开播放器，不会自动播放。
  • 点击播放按钮播放上一次听的歌曲；点击播放器上的歌名或歌手进入歌单。
  • 播放器支持列表循环、单曲循环和随机播放。列表循环到最后一首后会回到第一首。
  • 没有音频文件的占位歌曲会标注「暂无音频」，播放时会给出提示。

2. 歌单与本地音乐

  • 歌单中可以直接选歌、推荐给对方，或邀请对方一起听。
  • 点击「＋」可以导入本地 mp3；文件保存在浏览器本地数据库中，关闭页面后仍然保留。
  • 歌词支持导入 .lrc 文件，也可以使用内置歌词。内置歌词在打包时写入，不依赖网络读取。

3. 一起听

推荐歌曲后，对方会在几秒内给出回应。邀请对方一起听时，如果这首歌正好是当前正在播放的歌曲，不会从头重新播放。

4. 音乐管理

后台的「音乐管理」可以调整曲目顺序、隐藏不常听的曲目、批量删除，并检查音频文件是否存在。删除本地曲目前会二次确认；隐藏的曲目可以从同一页面恢复。

七、数据管理

  • 占用空间：显示当前浏览器中聊天数据、字卡和图片/语音的大致体积。
  • 导出：可以导出全部数据、字卡与表情库、聊天记录或聊天设置。导出前可选择是否包含图片和语音。
  • 导入：选择之前导出的 JSON 文件，或粘贴导出的文本内容。导入会覆盖对应类别的现有数据，操作前建议先备份。
  • 清理图片/语音：只移除图片和语音，文字消息保留。
  • 清空聊天记录：删除全部聊天消息，字卡和设置不受影响。

如果超过 7 天没有导出，或从未导出过，进入数据管理时会收到一次备份提醒；同一天最多提醒一次。

八、概率说明

以下比例用于让对话更接近日常聊天，不是固定流程。每次触发都会重新随机。

情绪气泡的三个阶段

情绪气泡按场景分为三个阶段：日常阶段没有等待中的回复，以平静、开心为主；刚分开阶段是他刚发完消息的一小段时间，期待和等待会上升；久未回阶段时间越长越偏平静，焦虑先升后降。未拆的红包或礼物会临时压过其他情绪，偏向等待和不安。点开他推荐的歌、拆礼物、领红包、看他发来的位置，也会按内容强弱影响情绪；礼物越贵、红包金额越大，正向情绪通常越强，520、1314 这类金额还会更偏向亲密。你发出互动、邀请或选择卡后如果还没被回应，期待和不安会轻微上升。同一状态通常至少保持约 40 秒，避免频繁变化。对方离线时情绪气泡会隐藏，恢复在线后再出现。

气泡最多显示三段，但每次刷新不一定三段都有：可能只有一段、两段或三段。第一段一定是情绪，第二、三段可能是进一步状态、等待/看手机这类通用补充，或另一条情绪。部分情绪会出现「开心 / 开心+ / 开心++」这样的强度标记；第三段也可能以 emoji 收尾。切到另一条情绪时按亲和权重，不是完全平均：委屈更容易接期待，开心更容易接激动，但其他情绪仍保留低概率。待机久了可能升一档，也可能切换情绪。换情绪时整颗气泡会缩放回弹、扫过一道高光并变色；升一档时只有气泡横向长开、新加的那一段弹进来，颜色保持不变，两种效果有明显区别。拍一拍之后，普通情绪会先隐藏，等下一次真实消息再显示。

熬夜与离线

00:00～05:00 登录，或在深夜长时间停留在界面，会提高担心、不安、焦虑、生气的权重，并可能出现一次熬夜相关的情绪。深夜离线的概率会略高。对方切到 2G 或离线时会弹出「📶 对方网络不佳，回复可能会慢一点」或「📴 对方已掉线，消息可能会晚一点」提示；2G 每次回复约多等 10 秒，进入文字回复时约 55% 说「卡死了」这类慢网短句、45% 继续从字卡库抽取。网络恢复后，如果这段 2G 里你发过消息，他可能补一句「刚才太卡了，现在终于好了」，情绪也会按等待的消息数偏向抱歉、无奈或焦急。离线时一般同步显示 2G。状态持续期间，距上次提示约 5 秒后再次发消息还会看到一次提示，直到对方恢复。连续发多条消息会增加等待、焦虑、不安的权重；离线回来时会根据消息数量偏向等待、担心或焦急。离线时约 2 秒后先发一条带「[自动回复]」的消息：80% 从内置短句抽取（「你要好好吃饭」「喝水了吗？记得多喝水」「睡不够就好好休息」「我马上就会回来了」「正在朝你飞奔而来...」「转人工」），20% 从字卡库抽取。离线时发的互动、邀请、选择卡会等你上线后才接受；发消息、发互动、打电话都会让他更容易提前上线，离线时电话接通率更低；等待时间一部分约 2～10 秒、一部分约 10～20 秒；没接通保持离线，接通后才转上线并保持在线。离线攒下的互动、邀请、选择卡会在上线后一条条隔几秒回应，不会同时弹出。离线未接来电不会在他还离线时立刻回复，等他上线后才补一句；如果之后有电话接通，就不再补未接回复。显示「对方已挂断」说明他已经上线并主动挂断，会转为在线并用普通挂断回复。约 90～240 秒后才真正回来，并按睡觉、工作、手机关机/没看到等离线原因选择回来文案，深夜更容易抽到「刚睡醒」类；不再带自动回复标记。

项目规则
普通文字回复从字卡库随机抽取；约 20% 会引用你最近说过的一句话；约 30% 会在末尾附加一个 Emoji。
2G 文字回复约 55% 说「卡死了」这类慢网短句，45% 继续抽字卡；拍一拍、音乐、礼物、图片仍先按原概率判定。网络恢复后可能补一句「刚才太卡了，现在终于好了」。
回复中的额外行为约 6% 触发拍一拍；约 3% 分享或邀请一起听歌（其中邀请约 1.05%）；约 5% 发送礼物、红包或转账。
音乐事件冷却分享歌曲或邀请一起听后，8 分钟内不会再次随机出现音乐事件，避免连续听歌。

九、常见问题

1. 聊天记录在哪里？

全部保存在当前浏览器中。清理浏览器缓存、更换浏览器或使用无痕模式都可能导致记录消失。建议定期导出备份。

2. 换设备后如何继续？

在旧设备导出「全部数据」，将 JSON 文件发送到新设备，再在新设备的数据管理中导入。两台设备之间不会自动同步。

3. 内置音乐无法播放怎么办？

本地导入的 mp3 和歌词可以正常播放。内置曲目需要整个 music 文件夹随网站一起部署，而不只是打开 index.html；没有音频文件的曲目会显示「暂无音频」。手机浏览器需要由用户主动点击播放按钮。第一次播放一首歌要先读取 mp3，文件较大或网络较慢时会显示「加载中…」；打开播放器会先预载当前歌曲，只要还有数据持续到达就不会判定超时，完全没有新数据超过约 45 秒才提示「加载超时」。

4. 安装到桌面后图标是字母怎么办？

请确认网站使用 https 访问、icons 文件夹已上传，然后删除旧快捷方式、清理缓存并重新添加。

5. 忘记支付密码怎么办？

支付密码保存在本机，无法找回。只能清理站点数据后重新设置，请在操作前确认已经备份重要内容。

6. 为什么有时回复很快，有时很久？

回复延迟由聊天设置决定，并在设定范围内随机。空闲时间、是否离线、是否有未领取的卡片也会影响情绪和回复节奏。

7. 退出重进后为什么少了一段消息？

聊天记录平时存在浏览器 localStorage；2G、离线、多开页面或存储写满时，旧页面可能来不及保存。现在保存前会合并其他页面的新消息，并额外在 IndexedDB 留一份备份；重新打开时如果发现备份更新会自动恢复。若看到「本地存储已满」提示，请先导出备份，再清理旧图片或语音，不要直接清空全部数据。

本手册随功能更新同步维护。如需调整具体数值或文案，请参考《代码说明》。
