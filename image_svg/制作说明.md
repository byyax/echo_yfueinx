# 怎么自己做 SVG 插画

这个文件夹里的 `.svg` 文件都可以直接用 VSCode 打开修改。SVG 本质上是文本，不是只能靠软件导出的图片。

## 1. 用 VSCode 打开

1. 打开 VSCode；
2. 文件 → 打开文件夹；
3. 选择 `D:\Echo_yfueinx14.0\photo_samples`；
4. 点开 `_template.svg`，看到的就是源代码；
5. 改完后按 `Ctrl + S` 保存；
6. 在文件管理器里双击这个 SVG，用 Edge 打开预览；改一次、刷新一次即可。

可选：在 VSCode 扩展里安装 `SVG Preview` 或 `Live Preview`，可以边改边看。没有扩展也不影响，浏览器就是最好的预览器。

## 2. 坐标系

- 画布是 `viewBox="0 0 800 600"`；
- 左上角是 `(0, 0)`；
- `x` 向右变大，`y` 向下变大；
- 最终是 4:3，宽 800、高 600。

## 3. 最常用的标签

```svg
<rect x="100" y="100" width="200" height="120" rx="20" fill="#E8D5C0"/>
<circle cx="400" cy="300" r="80" fill="#FFF"/>
<ellipse cx="400" cy="300" rx="120" ry="60" fill="#FFF"/>
<line x1="100" y1="100" x2="300" y2="200" stroke="#333" stroke-width="4"/>
<path d="M100 300 Q200 150 400 300 T700 300" fill="none" stroke="#333" stroke-width="6"/>
```

`path` 的常用命令：

- `M`：移动到某个点；
- `L`：画直线；
- `Q`：二次曲线；
- `C`：三次曲线；
- `A`：圆弧；
- `Z`：闭合路径。

## 4. 分层顺序

SVG 是“后画的盖住先画的”。推荐顺序：

1. 背景色；
2. 远处的大形状；
3. 桌面/地面；
4. 阴影；
5. 主体物体；
6. 小道具；
7. 高光、蒸汽、颗粒；
8. 最后再叠加暗角。

## 5. 渐变和阴影

渐变放在 `<defs>` 里，然后通过 `url(#id)` 使用：

```svg
<defs>
  <linearGradient id="sky" x1="0" y1="0" x2="0" y2="1">
    <stop offset="0" stop-color="#FFB07A"/>
    <stop offset="1" stop-color="#6C4C7A"/>
  </linearGradient>
  <filter id="blur">
    <feGaussianBlur stdDeviation="12"/>
  </filter>
</defs>

<rect width="800" height="600" fill="url(#sky)"/>
<ellipse cx="400" cy="460" rx="180" ry="30" fill="#000" opacity=".3" filter="url(#blur)"/>
```

## 6. 防止边缘溢出

边缘看起来“被切掉”或“溢出去”，通常是这几个原因：

- 图形坐标超出 `0～800 / 0～600`；
- 线条有宽度，`x=0` 的线会有一半画在画布外；
- 模糊/阴影会向外扩散；
- 旋转或放大后的组超出边界；
- 没有给整个画面加裁剪。

最稳的做法：

```svg
<defs>
  <clipPath id="frameClip">
    <rect width="800" height="600" rx="24"/>
  </clipPath>
</defs>

<g clip-path="url(#frameClip)">
  <!-- 所有画面内容 -->
</g>
```

同时留出 **24px 安全边距**。`_template.svg` 里已经放了红色虚线安全框，作品完成后把 `id="guides"` 那一组删掉即可。

## 7. 建议的练习顺序

1. 复制 `_template.svg` 为 `my_first.svg`；
2. 先只改背景色和桌子颜色；
3. 再移动杯子位置；
4. 再改杯子形状、加一个小碟子；
5. 最后加渐变、阴影和一点蒸汽；
6. 保存后刷新浏览器看效果。

不要一上来就画很复杂的场景。先把“背景 + 一个主体 + 一个道具 + 一个阴影”画顺，再往上加东西。
