Echo Yfueinx · 使用手册

这本手册只讲怎么用，不需要懂代码。想改颜色、改概率、加歌、改文案，请看另一本《代码说明》。

请注意：所有聊天记录、字卡和设置都只保存在当前浏览器中。换手机、换浏览器、清理浏览器数据，都可能丢失，建议定期导出备份。网站后台也内置了一份同样的手册：聊天页右上角「⋯」→「使用手册」。

一、第一次打开

1. 用网址打开

在手机或电脑浏览器里输入你的网址（https://...github.io/...）。不要从文件管理器里直接点 index.html，那样麦克风和安装功能都会失效。

2. 建议先安装到桌面

  • 安卓 Chrome / Edge：右上角 ⋮ →「安装应用」或「添加到主屏幕」；
  • 苹果 Safari：底部「分享」→「添加到主屏幕」；
  • 电脑 Chrome：地址栏右侧的安装小图标；
  • 电脑 Edge：右上角 ⋯ →「更多工具」→「应用」→「安装此站点为应用」。

装好后从桌面点开，是全屏的，没有地址栏。

3. 数据在本机

第一次打开是空存档。你发的消息、加的字卡、换的配色，都保存在当前浏览器。 换浏览器或换手机不会自动同步，要用「数据管理」导出再导入。

二、界面说明

顶栏

  • 左边是他的名字；
  • 名字右边两行：第一行是他的状态（在线、摸鱼、听歌中…），第二行是网络和电量（网络会自己变化，2G 会轻微拖慢回复）；
  • 右上角三个按钮：
  • 🌙 / ☀️：切换黑夜/白天模式；
  • 🖥️：PC 宽屏模式；
  • ⋯：打开后台管理。

签名栏

名字下面那一条，是他的个性签名。打开网站时有 40% 概率换一条；平时大约每 15–30 分钟换一次（大概率），并且会尽量避开当前这句，不会一直停在同一条。播放音乐时，这里可能变成歌词。

输入栏

从左到右：

  • 输入框：打字；
  • 😄：表情面板；
  • ＋：工具面板（拍照、图片、通话、位置、红包、礼物、转账、互动、音乐、录音）；
  • 💌：让他主动给你发消息；
  • 发送。

三、聊天

发消息

打字 → 发送。发送后他会在设定时间内的某个时刻回复，可能先显示「正在输入」。

引用

双击某条气泡，或长按气泡选「引用」，输入框上方会出现引用条，再发送就是回复那条。

删除

长按气泡（电脑右键）→「删除」。

历史记录很长时

首屏只加载最近约 200 条消息，避免手机一次创建太多内容。聊天顶部会出现「加载更早的 N 条消息」按钮，点一次继续加载上一批。聊天数据仍然完整保存，不会因为分页而丢失。

拍一拍

双击他的头像，就是「你拍了拍他」。聊天中间会出现一行灰色小字，不是气泡，这是正常的。

让他主动

点输入栏右边的 💌，他会按设置里的条数主动发消息。

图片、拍照、位置

  • 拍照：手机直接开相机，电脑上会变成选文件；
  • 图片：从相册选，太大的图会自动压缩；
  • 他在哪：从他自己的「位置库」里随机发一个位置给你。

语音

点 ＋ → 录音，按住说话（具体见第八节）。

四、字卡与表情

自定义回复（字卡）

后台 → 自定义回复 → 字卡。他每次随机回复，就是从这些字卡里抽一条发给你。

  • 可以建多个标签分类；
  • 支持批量粘贴，一行一条；
  • 有查重功能，重复的会标出来；
  • 标签名字会影响情绪：比如标签里有「吃醋」，他抽到这张卡后更容易吃醋。

Emoji

😄 打开表情面板，分三页：Emoji / 我的表情 / 他的表情。 Emoji 可以直接点着发；表情包图片也可以发。

五、互动与拍一拍

互动

＋ → 互动，选一个动作：摸摸头、戳戳脸、抱抱、贴贴、捏捏脸、举高高……他会用对应的语气回你。每个动作的回复可以自己加。

拍一拍

  • 你拍他：双击他的头像，文案在「聊天设置 → 我的拍一拍」里改；
  • 他拍你：会从他自己的「拍一拍库」里随机抽一条；
  • 显示形式：聊天中间一行灰色小字，像微信一样。

六、红包、转账、礼物

你发红包

＋ → 红包 → 填金额和备注 → 发送。他过几秒会自动领。

你转账

＋ → 转账 → 填金额。第一次会要求设置 6 位支付密码，之后每次转账都要输。密码忘了可以在数据管理里清空全部数据（会丢存档，谨慎）。

送礼物

＋ → 送礼物：

  • 礼物商城：按价位、类型筛选；
  • 自定义礼物：自己写礼物名字，图标固定蝴蝶结。

他收到后会过几秒拆开。

他送你

他偶尔会随机送红包、转账或礼物，还会抽特殊数字：52、520、5200、1314、8888、你的生日 710、他的生日 1112 等等。金额越大越难出现，可视为彩蛋。

七、语音通话

＋ → 语音通话，就是打给他。

  • 他可能接、可能拒接、可能不接；
  • 他也会偶尔主动打给你，屏幕上会出现接听/拒绝；
  • 通话中可以把大窗口缩成小窗，小窗可以拖动；
  • 通话结束后聊天里会留一条带电话图标的通话记录；
  • 通话结果会影响他接下来的心情，并可能触发一句通话后的回复。

通话记录共有五种主要结果：

  1. 他打给你，铃声响完你未接：显示「未接来电」；
  2. 你打给他，铃声响完他未接：显示「对方未接来电」；
  3. 你打给他，他未接就挂断：显示「对方已挂断」；
  4. 他打给你，你未接就挂断：显示「已挂断」；
  5. 接通后结束：显示「通话结束 时长」。

未接和挂断使用红色电话图标，正常结束使用主题色图标；你主动取消尚未接通的通话时，记录为「已取消」。通话记录之后，他通常会按情况回复一句：未接和挂断约 60% 使用内置句子、40% 抽取你的字卡；通话结束和已取消约 50% / 50%。字卡库为空时使用内置句子，内置句子约 42% 在末尾附加 emoji。

八、录音

＋ → 录音。

  1. 第一次会弹麦克风权限，点允许；
  2. 计时开始，最长 60 秒；
  3. 点「发送」结束并发出，点「取消」丢弃；
  4. 取消、退出页面、切到别的 App，都会立刻停掉麦克风。

注意：录音只在 https 网址下可用，本地双击 html 不行。

九、音乐

打开播放器

＋ → 音乐。播放条会出现在输入框上方。

控制

  • ▶ / ⏸：播放暂停；
  • ⏮ / ⏭：上一首 / 下一首；
  • 🔁：切换列表循环 / 单曲循环 / 随机；
  • ＋：导入本地 mp3；
  • 播放条顶部中间的小拉条：点击收起播放器，再次点击展开；收起后歌曲继续播放，不占聊天空间；
  • ✕：关闭播放条（不会停止播放）。

歌单

点播放条中间的歌名区域，会打开歌单：

  • 点歌播放；
  • 「词」可以给这首歌导入歌词；
  • 「一起」可以邀请他一起听；
  • 「推荐」可以把这首歌分享到聊天里；
  • 「删」删除本地导入的歌，删除前会二次确认。

导入 mp3 和歌词

  • 支持 mp3；.ncm 是网易云加密格式，不能直接用，要先导出成 mp3；
  • 可以同时选 .lrc 歌词，文件名和歌名一致会自动对上；
  • 双语歌词：再选一个「歌名.zh.lrc」，或者同一时间戳写两行；
  • 导入的歌存在浏览器里，退出再进来还在。

播放状态

播放条上会显示当前状态：

  • 「加载中…」：正在读取音频，尤其是 7–10MB 的大文件，手机上要等几秒；
  • 「文件找不到或格式不支持」：多半是 mp3 没上传、路径不对，或者文件损坏；
  • 「网络错误」「解码失败」：网络或文件本身有问题；
  • 20 秒还没加载出来，会提示「加载超时」。

想一次检查所有带文件的歌：后台 → 音乐管理 → 批量管理 → 「检测」。检查结果显示在工具栏下方，会列出哪些歌读不到，方便判断是没上传还是网络慢。

一起听

他偶尔会分享歌或邀请你一起听；你也可以在歌单里点「一起」邀请他。你发出邀请后，他回复时卡片会变成「已接受」，并自动打开播放器播放那首歌。如果是他邀请你，点击卡片上的「好呀」也会直接播放；同一首歌正在播放时不会重播。

手机 / 电脑上的加号面板

  • 分两页，每页 4 列 2 行；
  • 第一页是拍照、图片、语音通话、他在哪、红包、送礼物、转账、互动；
  • 第二页从第一行开始，放音乐和录音；
  • 左右滑动或点底部两个小圆点切换，圆点会按当前配色高亮；
  • 电脑上鼠标滚轮上下滚也能翻页，切换带滑动动画。

批量管理

后台 → 音乐管理，顶部有「批量管理」：

  • 勾选歌曲后，可以用「上移 / 下移」调整顺序；
  • 点「删除」可以一次删掉选中的歌；
  • 删除本地导入的歌会二次确认，并同时删掉音频；删除内置歌会先隐藏，展开「说明」后可以「恢复隐藏的曲目」；
  • 顺序会自动保存，下次打开还是这个顺序。

旁边的「说明」按钮可以展开或收起导入规则的长说明。

十、情绪气泡

他最后一条消息下面，会有一个小气泡，比如「开心 | 在线」「吃醋 | 不说」。这是他的心情，不同颜色代表不同情绪：

  • 绿：开心、平静；
  • 橙：激动；
  • 玫瑰：亲密；
  • 紫：吃醋；
  • 橘红：烦躁；
  • 蓝灰：伤心；
  • 琥珀：不安；
  • 浅橙：焦虑；
  • 深灰蓝：隐忍；
  • 土黄：期待。

心情会随聊天内容、红包、听歌、抱抱、你很久没回而变化。情绪按三个阶段调整：

  • 日常阶段：没有等待中的回复，以平静、开心为主；
  • 刚分开阶段：他刚发完消息的一小段时间，期待和等待会上升；
  • 久未回阶段：时间越长越偏平静，焦虑先升后降；未拆的红包或礼物会临时压过其他情绪。

气泡最多显示三段，但每次刷新不一定三段都有，可能只有一段、两段或三段；待机久了可能升档，也可能切换情绪。第一段一定是情绪，第二、三段可能是进一步状态、等待/看手机这类通用补充，或另一条情绪。部分情绪会出现「开心 / 开心+ / 开心++」的强度标记；第三段也可能以 emoji 收尾。换情绪时整颗气泡会缩放回弹、扫过一道高光并变色；升档时只有气泡横向长开、新加的那一段弹进来，颜色保持不变。拍一拍之后，普通情绪会先隐藏，等下一次真实消息再显示。

很久没打开后再回来，他更容易是「开心 / 回来啦」或「想你 / 终于来了」。如果最后一条是你发的，气泡会先藏起来，等他回了才显示——这不是 bug。

十一、聊天设置

后台 → 聊天设置。

基本

  • 对方昵称、我的昵称；
  • 头像、壁纸：选择文件，可以拖动裁剪；对方未设置头像时，默认显示像素爱心，并跟随当前配色；
  • 恢复默认头像 / 恢复默认壁纸：清除自定义图片，点击保存后生效；
  • 个性签名；
  • 签名切换间隔：15–60 分钟可选，实际会在这个值到 2 倍之间随机；
  • 时间格式：时分 / 时分秒，12 / 24 小时制，保存后立刻生效。

回复节奏

  • 回复延迟：他隔多久回你，单位分钟；
  • 回复条数：一次主动发几条；
  • 定时回复：你多久不说话，他主动发；
  • 显示「正在输入」；
  • 消息与通话音效开关；
  • 情绪气泡：控制最后一条消息下方是否显示心情气泡，默认开启。
  • 开场动画染色：开启时启动页跟随当前界面配色；关闭时启动页固定使用默认绿色。

拍一拍

  • 我的拍一拍动作（默认「拍了拍」）；
  • 后缀（默认「的后背」）。

界面配色

五组共 35 套：

  • 单色：浅色底，6 套；
  • 撞色：有底色，11 套；
  • 渐变：8 套；
  • 科技：黑白灰银，4 套；
  • 其他：微信、Telegram、QQ、LINE、WhatsApp、iMessage，6 套。

白天完整应用；黑夜模式的按钮和气泡会跟随当前主色，其余界面仍使用统一深色方案。启动页的光晕、进度条和爱心也会跟随配色。对方未设置头像时的默认像素爱心，在黑夜模式沿用与白天相同的滤镜，不会偏成另一种颜色。

点击后立即预览，保存后生效。「图标色调」有三档：原色 / 柔和 / 跟随配色。

十二、数据管理

后台 → 数据管理。

看占用

能看到 localStorage 总大小、消息条数、卡片数量、图片/语音占用。

导出

可以选：

  • 全部数据（设置、配色、主题、歌词、字卡、聊天记录）；
  • 字卡与表情库；
  • 聊天记录；
  • 聊天设置。

「导出时带上图片」开关：

  • 开：图片和语音会一起导出，文件很大；
  • 关：图片/语音变成「[图片已省略]」，文件小。

导入

支持选文件或粘贴文本。导入「全部」会恢复设置、配色、主题、字卡、歌词和聊天记录。

清理

  • 只清理图片/语音：保留所有文字；
  • 清空聊天记录；
  • 清空全部数据：会连设置一起清掉，谨慎。

换设备

  1. 旧设备导出「全部数据」；
  2. 把 JSON 发到新设备；
  3. 新设备打开网站 → 数据管理 → 导入 → 选文件。

本地导入的 mp3 不会跟着 JSON 走，需要在新设备重新导入。

安卓（Chrome / Edge）

打开网址 → 右上角 ⋮ →「安装应用 / 添加到主屏幕」。

苹果（Safari）

电脑（Chrome / Edge）

Chrome：地址栏右侧的安装图标，或 ⋮ →「更多工具」→「创建快捷方式」；Edge：右上角 ⋯ →「更多工具」→「应用」→「安装此站点为应用」。

QQ 浏览器

只能「添加到桌面」生成快捷方式，不是真正的 App：点开仍有地址栏，图标也可能变成字母。想要完整效果，用 Chrome / Edge 安装。

图标是字母怎么办

  • 确认网址是 https；
  • 确认 icons 文件夹已经上传；
  • 删掉旧快捷方式，清一次浏览器缓存，再重新添加。

十五、数据安全提醒

  1. 这个网站没有服务器，没有人能帮你找回数据；
  2. 换浏览器、换设备、清缓存、无痕模式，都可能导致数据丢失；
  3. 建议每周导出一次「全部数据」，存到网盘或电脑里；
  4. 支付密码也在本机，忘了只能清空数据重来；
  5. 公开分享网址不会泄露你的聊天记录——记录只在你自己浏览器里。

十六、想改东西？

如果只是想换颜色、加一首歌、改回复概率，不需要动代码结构，翻到另一本《代码说明》，里面按「功能 → 在哪个文件 → 怎么改 → 怎么检查 → 常见 bug」写好了。

  • 加歌、加礼物、加互动动作、加情绪：第七节；
  • 换浏览器标签图标、桌面图标：第八节；
  • 开场动画的结构和放行逻辑：第九节。

十七、v12 新增与变化

选择

加号面板第二页 →「选择」。默认两条选项，可以继续添加；填「从中选几个」后发送。对方会先显示「思考中…」，然后回复「我选xx」或「我选xx，xx，xx」。点击卡片可展开，选中的项会显示勾选标记。

音乐

点击「音乐」只弹出播放器，不会自动播放上次的歌。点击播放按钮会播放上次那首；如需换歌，点击播放器上的歌名进入歌单。一起听时，如果这首正好是当前正在播的，不会从头重播。推荐歌曲给他后，他会过几秒回应：可能是内置听歌回复，也可能是你的字卡。顺序播放会首尾循环；标「暂无音频」的歌需要先把 mp3 放进 music/。手机播放内置音乐时，必须把整个 music/ 文件夹一起放好，不能只传 index.html；本地导入的 mp3 和歌词不受此限制。

启动与备份

启动页新增进度条，会等页面、字体、图片都准备好再进入；背景有像素斜流星，开启「开场动画染色」时背景、爱心、光晕和流星跟随当前配色，关闭时统一使用默认橄榄绿。完全退场后，情绪气泡才会播放首次出现动画，不会在加载阶段提前播完。打开「数据管理」时，如果超过 7 天没导出，会弹一次备份提醒，一天最多一次。

新的初始默认

只在没有旧存档时生效：昵称「小云」、6 张文字卡、🥺🥰 两个 Emoji、两条拍一拍、三条签名、7 个位置，以及一批外卖/早餐/零食礼物。已有存档不会被覆盖；想用新默认值，请先导出备份，再清空站点数据。

手机与电脑同步

纯静态网站没有服务器，不能自动通过同一个 WiFi 发现并同步。可行方式是「数据管理 → 导出全部数据」，在另一台设备导入。自动同步需要额外的本地服务端，超出静态网页范围。

  • 如字卡库为空，互动、推荐歌曲和通话后回复会使用内置回复；普通聊天会弹出提示，可直接前往自定义回复添加字卡；

  • 通话后的内置句子约 42% 会在末尾附加 emoji；
  • 切到另一条情绪时按亲和权重：委屈更容易接期待，开心更容易接激动，但其他情绪仍保留低概率。

十九、熬夜与离线

  • 00:00～05:00 登录，或在深夜长时间停留在界面，会提高担心、不安、焦虑、生气的权重，并可能触发一次熬夜情绪；
  • 深夜离线的概率会略微提高；
  • 对方切到 2G 时会弹出「📶 对方网络不佳，回复可能会慢一点」提示；2G 状态下每次回复会比正常延迟多约 10 秒；
  • 对方变成离线时会弹出「📴 对方已掉线，消息可能会晚一点」提示，离线时一般也会同步显示 2G；恢复在线后不再提示；
  • 如果 2G 或离线持续存在，你每 10 秒后再次发消息时还会看到一次状态提示，直到对方恢复；
  • 在 2G 或离线期间连续发多条消息，等待、焦虑、不安的权重会随消息数量上升；离线回来时会根据你留下的消息数量，偏向「等待 / 担心 / 焦急」，不会都按同一种情况处理；
  • 离线自动回复会带「[自动回复]」标记；回到在线后，新消息不再带这个标记，历史消息保留当时的标记；
  • 离线回来的文案包括「刚刚没看手机，怎么啦？」「不好意思，我睡着了..」「我才忙完回来，我好想你」「刚上线，我把你的消息看完了」「立刻朝你飞奔过来」，较高概率在结尾带 😭 或 🥺。
