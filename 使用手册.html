Echo Yfueinx · 使用手册

这本手册只讲怎么用，不需要懂代码。想改颜色、改概率、加歌、改文案，请看另一本《代码说明》。

记住一件事：所有聊天记录、字卡、设置都只存在你自己的浏览器里。换手机、换浏览器、清理浏览器数据，都可能丢，记得定期导出备份。

一、第一次打开

1. 用网址打开

在手机或电脑浏览器里输入你的网址（https://...github.io/...）。不要从文件管理器里直接点 index.html，那样麦克风和安装功能都会失效。

2. 建议先安装到桌面

  • 安卓 Chrome / Edge：右上角 ⋮ →「安装应用」或「添加到主屏幕」；
  • 苹果 Safari：底部「分享」→「添加到主屏幕」；
  • 电脑 Chrome / Edge：地址栏右侧的安装小图标。

装好后从桌面点开，是全屏的，没有地址栏。

3. 数据在本机

第一次打开是空存档。你发的消息、加的字卡、换的配色，都保存在当前浏览器。 换浏览器或换手机不会自动同步，要用「数据管理」导出再导入。

二、界面说明

顶栏

  • 左边是他的名字；
  • 名字右边两行：第一行是他的状态（在线、摸鱼、听歌中…），第二行是网络和电量（装饰用，会自己变）；
  • 右上角三个按钮：
  • 🌙 / ☀️：切换黑夜/白天模式；
  • 🖥️：PC 宽屏模式；
  • ⋯：打开后台管理。

签名栏

名字下面那一条，是他的个性签名。打开网站时有 40% 概率换一条；平时大约每 15–30 分钟换一次（大概率），并且会尽量避开当前这句，不会一直停在同一条。播放音乐时，这里可能变成歌词。

输入栏

从左到右：

  • 输入框：打字；
  • 😄：表情面板；
  • ＋：工具面板（拍照、图片、通话、位置、红包、礼物、转账、互动、音乐、录音）；
  • 💌：让他主动给你发消息；
  • 发送。

三、聊天

发消息

打字 → 发送。发送后他会在设定时间内的某个时刻回复，可能先显示「正在输入」。

引用

双击某条气泡，或长按气泡选「引用」，输入框上方会出现引用条，再发送就是回复那条。

删除

长按气泡（电脑右键）→「删除」。

拍一拍

双击他的头像，就是「你拍了拍他」。聊天中间会出现一行灰色小字，不是气泡，这是正常的。

让他主动

点输入栏右边的 💌，他会按设置里的条数主动发消息。

图片、拍照、位置

  • 拍照：手机直接开相机，电脑上会变成选文件；
  • 图片：从相册选，太大的图会自动压缩；
  • 他在哪：从他自己的「位置库」里随机发一个位置给你。

语音

点 ＋ → 录音，按住说话（具体见第八节）。

四、字卡与表情

自定义回复（字卡）

后台 → 自定义回复 → 字卡。他每次随机回复，就是从这些字卡里抽一条发给你。

  • 可以建多个标签分类；
  • 支持批量粘贴，一行一条；
  • 有查重功能，重复的会标出来；
  • 标签名字会影响情绪：比如标签里有「吃醋」，他抽到这张卡后更容易吃醋。

Emoji

😄 打开表情面板，分三页：Emoji / 我的表情 / 他的表情。 Emoji 可以直接点着发；表情包图片也可以发。

五、互动与拍一拍

互动

＋ → 互动，选一个动作：摸摸头、戳戳脸、抱抱、贴贴、捏捏脸、举高高……他会用对应的语气回你。每个动作的回复可以自己加。

拍一拍

  • 你拍他：双击他的头像，文案在「聊天设置 → 我的拍一拍」里改；
  • 他拍你：会从他自己的「拍一拍库」里随机抽一条；
  • 显示形式：聊天中间一行灰色小字，像微信一样。

六、红包、转账、礼物

你发红包

＋ → 红包 → 填金额和备注 → 发送。他过几秒会自动领。

你转账

＋ → 转账 → 填金额。第一次会要求设置 6 位支付密码，之后每次转账都要输。密码忘了可以在数据管理里清空全部数据（会丢存档，谨慎）。

送礼物

＋ → 送礼物：

  • 礼物商城：按价位、类型筛选；
  • 自定义礼物：自己写礼物名字，图标固定蝴蝶结。

他收到后会过几秒拆开。

他送你

他偶尔会随机送红包、转账或礼物，还会抽特殊数字：52、520、5200、1314、8888、你的生日 710、他的生日 1112 等等。金额越大越难出现，当作彩蛋就好。

七、语音通话

＋ → 语音通话，就是打给他。

  • 他可能接、可能拒接、可能不接；
  • 他也会偶尔主动打给你，屏幕上会出现接听/拒绝；
  • 通话中可以把大窗口缩成小窗，小窗可以拖动；
  • 通话结束后聊天里会留一条通话记录；
  • 通话结果会影响他接下来的心情。

八、录音

＋ → 录音。

  1. 第一次会弹麦克风权限，点允许；
  2. 计时开始，最长 60 秒；
  3. 点「发送」结束并发出，点「取消」丢弃；
  4. 取消、退出页面、切到别的 App，都会立刻停掉麦克风。

注意：录音只在 https 网址下可用，本地双击 html 不行。

九、音乐

打开播放器

＋ → 音乐。播放条会出现在输入框上方。

控制

  • ▶ / ⏸：播放暂停；
  • ⏮ / ⏭：上一首 / 下一首；
  • 🔁：切换列表循环 / 单曲循环 / 随机；
  • ＋：导入本地 mp3；
  • ✕：关闭播放条（不会停止播放）。

歌单

点播放条中间的歌名区域，会打开歌单：

  • 点歌播放；
  • 「词」可以给这首歌导入歌词；
  • 「一起」可以邀请他一起听；
  • 「推荐」可以把这首歌分享到聊天里；
  • 「删」删除本地导入的歌。

导入 mp3 和歌词

  • 支持 mp3；.ncm 是网易云加密格式，不能直接用，要先导出成 mp3；
  • 可以同时选 .lrc 歌词，文件名和歌名一致会自动对上；
  • 双语歌词：再选一个「歌名.zh.lrc」，或者同一时间戳写两行；
  • 导入的歌存在浏览器里，退出再进来还在。

播放状态

播放条上会显示当前状态：

  • 「加载中…」：正在读取音频，尤其是 7–10MB 的大文件，手机上要等几秒；
  • 「文件找不到或格式不支持」：多半是 mp3 没上传、路径不对，或者文件损坏；
  • 「网络错误」「解码失败」：网络或文件本身有问题；
  • 20 秒还没加载出来，会提示「加载超时」。

想一次检查所有带文件的歌：后台 → 音乐管理 → 批量管理 → 「检测」。检查结果显示在工具栏下方，会列出哪些歌读不到，方便判断是没上传还是网络慢。

一起听

他偶尔会分享歌或邀请你一起听；你也可以在歌单里点「一起」邀请他。你发出邀请后，他回复时卡片会变成「已接受」，并自动打开播放器播放那首歌。如果是他邀请你，点卡片上的「好呀」也会直接播放。

手机 / 电脑上的加号面板

  • 分两页，每页 4 列 2 行；
  • 第一页是拍照、图片、语音通话、他在哪、红包、送礼物、转账、互动；
  • 第二页从第一行开始，放音乐和录音；
  • 左右滑动或点底部两个小圆点切换，圆点会按当前配色高亮；
  • 电脑上鼠标滚轮上下滚也能翻页，切换带滑动动画。

批量管理

后台 → 音乐管理，顶部有「批量管理」：

  • 勾选歌曲后，可以用「上移 / 下移」调整顺序；
  • 点「删除」可以一次删掉选中的歌；
  • 删除本地导入的歌会同时删掉音频；删除内置歌会先隐藏，展开「说明」后可以「恢复隐藏的曲目」；
  • 顺序会自动保存，下次打开还是这个顺序。

旁边的「说明」按钮可以展开或收起导入规则的长说明。

十、情绪气泡

他最后一条消息下面，会有一个小气泡，比如「开心 | 在线」「吃醋 | 不说」。这是他的心情，不同颜色代表不同情绪：

  • 绿：开心、平静；
  • 橙：激动；
  • 玫瑰：亲密；
  • 紫：吃醋；
  • 橘红：烦躁；
  • 蓝灰：伤心；
  • 琥珀：不安；
  • 深灰蓝：隐忍；
  • 土黄：期待。

心情会随聊天内容、红包、听歌、抱抱、你很久没回而变化。 很久没打开后再回来，他更容易是「开心 / 回来啦」或「想你 / 终于来了」。如果最后一条是你发的，气泡会先藏起来，等他回了才显示——这不是 bug。

十一、聊天设置

后台 → 聊天设置。

基本

  • 对方昵称、我的昵称；
  • 头像、壁纸：选择文件，可以拖动裁剪；
  • 个性签名；
  • 签名切换间隔：15–60 分钟可选，实际会在这个值到 2 倍之间随机；
  • 时间格式：时分 / 时分秒，12 / 24 小时制，保存后立刻生效。

回复节奏

  • 回复延迟：他隔多久回你，单位分钟；
  • 回复条数：一次主动发几条；
  • 定时回复：你多久不说话，他主动发；
  • 显示「正在输入」；
  • 消息与通话音效开关。

拍一拍

  • 我的拍一拍动作（默认「拍了拍」）；
  • 后缀（默认「的后背」）。

界面配色

四组共 30 套：

  • 单色：白底，7 套；
  • 撞色：有底色，11 套；
  • 渐变：8 套；
  • 科技：黑白灰银，4 套。

点一下立刻预览，保存后生效。 「图标色调」有三档：原色 / 柔和 / 跟随配色。

十二、数据管理

后台 → 数据管理。

看占用

能看到 localStorage 总大小、消息条数、卡片数量、图片/语音占用。

导出

可以选：

  • 全部数据（设置、配色、主题、歌词、字卡、聊天记录）；
  • 字卡与表情库；
  • 聊天记录；
  • 聊天设置。

「导出时带上图片」开关：

  • 开：图片和语音会一起导出，文件很大；
  • 关：图片/语音变成「[图片已省略]」，文件小。

导入

支持选文件或粘贴文本。导入「全部」会恢复设置、配色、主题、字卡、歌词和聊天记录。

清理

  • 只清理图片/语音：保留所有文字；
  • 清空聊天记录；
  • 清空全部数据：会连设置一起清掉，谨慎。

换设备

  1. 旧设备导出「全部数据」；
  2. 把 JSON 发到新设备；
  3. 新设备打开网站 → 数据管理 → 导入 → 选文件。

本地导入的 mp3 不会跟着 JSON 走，需要在新设备重新导入。

十三、安装到桌面

安卓（Chrome / Edge）

打开网址 → 右上角 ⋮ →「安装应用 / 添加到主屏幕」。

苹果（Safari）

打开网址 → 底部「分享」→「添加到主屏幕」。

电脑（Chrome / Edge）

地址栏右侧的安装图标，或 ⋮ →「安装页面为应用」。

QQ 浏览器

只能「添加到桌面」生成快捷方式，不是真正的 App：点开仍有地址栏，图标也可能变成字母。想要完整效果，用 Chrome / Edge 安装。

图标是字母怎么办

  • 确认网址是 https；
  • 确认 icons 文件夹已经上传；
  • 删掉旧快捷方式，清一次浏览器缓存，再重新添加。

现象怎么处理

没有声音先点一下页面；检查设置里的音效开关；手机静音键
录音按钮不出现不是 https，或者浏览器不支持；换 Chrome
录音一直正在打开麦克风点取消；刷新页面；重新允许权限
麦克风一直亮关掉旧页面重新打开；强刷
聊天记录没了换浏览器/清缓存会丢；用之前导出的 JSON 导入
音乐没声.ncm 不能播；确认 mp3 已上传；换一首试试
歌词不滚歌名和歌词文件对不上；重新导入同名 lrc
桌面图标是字母用 https；补传 icons；删掉旧图标重加
他一直在“正在输入”等几秒；刷新；检查回复延迟是否设得太大
情绪一直不变最后一条是你发的时本来就隐藏；等他说了才显示
红包金额总是很小/很大随机区间 + 彩蛋，多试几次
手机很卡数据管理里只清理图片/语音，或导出后清空记录

十五、数据安全提醒

  1. 这个网站没有服务器，没有人能帮你找回数据；
  2. 换浏览器、换设备、清缓存、无痕模式，都可能导致数据丢失；
  3. 建议每周导出一次「全部数据」，存到网盘或电脑里；
  4. 支付密码也在本机，忘了只能清空数据重来；
  5. 公开分享网址不会泄露你的聊天记录——记录只在你自己浏览器里。
