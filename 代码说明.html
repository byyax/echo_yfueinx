这份文档是给你自己改着玩用的。按"文件 → 数据 → 新增功能步骤 → 排错"的顺序看就行，

不需要从头读到尾。

一、整体结构

没有框架、没有打包工具，就是普通网页：


index.html     页面骨架（所有页面、弹窗、启动画面都写在这里）
style.css      全部样式
*.js           按功能拆开，用普通的 <script> 依次加载

所有 js 共享同一个全局作用域——一个文件里定义的 function xxx()，别的文件可以直接调用。

所以加载顺序很重要，index.html 底部的顺序是：


data.js              ← 先有数据和默认设置
chat_sound.js        ← 音效（谁都能调用）
chat_core.js         ← 消息核心（sendMessage 在这里）
chat_stickers.js
chat_tools.js
chat_call.js
chat_money.js
manage_cards.js
manage_settings.js
manage_history.js
manage_data.js
music_lyrics.js      ← 内置歌词数据（必须在 chat_music 之前）
chat_music.js
manage_music.js
chat_mood.js
router.js            ← 页面切换、初始化渲染，放最后
custom_icons.js      ← 替换自定义图标
pwa.js               ← 注册 Service Worker

如果你新加一个 js，放在 router.js 之前、并且确保它依赖的函数已经加载。

三、数据存在哪

全部在浏览器的 localStorage 里（键名可以直接在 F12 → Application → Local Storage 里看）：

键内容
chat_settings所有设置（昵称、延迟、配色、开关…）
chat_history聊天记录数组
chat_contents / chat_tags字卡、标签
my_emojis我的表情
loc_library / poke_library / signature_library / interact_library位置、拍一拍、签名、互动
pay_password支付密码
echo_lyric_<歌名>自己导入的歌词（优先于内置）
echo_play_mode / echo_last_song播放模式、上次听的歌
export_media导出时是否带图片

另外本地导入的 mp3 存在 IndexedDB（数据库名 echo_music），不在 localStorage 里。

一条聊天记录长这样


{
  role: 'me' | 'other' | 'system',
  type: 'text' | 'image' | 'audio' | ...,
  content: { val: '正文', ... },
  time: 1699999999999
}

content 里可能出现的字段：

  • val：文字 / 图片 base64 / 语音 base64 / 位置文字
  • name artist：礼物名、歌名、歌手
  • amount note：红包金额、备注
  • icon：礼物或互动的图标
  • isOpened：红包/礼物是否已拆
  • quote：引用 {sender, text, time}
  • dur：语音时长（秒）

消息类型速查

text 文字 · image 图片 · audio 语音 · gift 礼物 · redpacket 红包 ·

transfer 转账 · interact 互动 · location 位置 · musicshare 推荐歌曲 ·

musicinvite 一起听 · sys 居中系统提示 · pat 拍一拍

颜色的约定：礼物卡片跟主题色走（card-icon.gift），红包固定红色（card-icon.red），
已拆开的礼物/红包用压暗的主色（card-icon.grey）。推荐歌曲和互动卡片用粉紫渐变。

四、这次新写入的 js，逐行解释

1. pwa.js


if ('serviceWorker' in navigator && location.protocol.indexOf('http') === 0) {

先判断两件事：浏览器支持 Service Worker 吗？页面是用 http/https 打开的吗？

（本地双击 html 是 file://，浏览器不允许注册，所以直接跳过，不会报错。）


  window.addEventListener('load', () => {
    navigator.serviceWorker.register('sw.js').catch(() => {});
  });

页面加载完之后注册 sw.js。.catch(() => {}) 是"失败了也别弹错误"，

因为注册失败不影响网站本身，只是不能安装到桌面。

它的作用：Chrome / Edge 只有在站点有 Service Worker 时，才会在地址栏显示"安装"按钮。

2. sw.js


self.addEventListener('install', () => self.skipWaiting());

skipWaiting() = 新版本立刻生效，不等旧页面关掉。


self.addEventListener('activate', (event) => event.waitUntil(self.clients.claim()));

clients.claim() = 立刻接管已经打开的页面。这两句是为了更新后不用手动刷新两次。


self.addEventListener('fetch', () => {});

空的 fetch 监听。必须有这一行——Chrome 判断"能不能安装"时要求有 fetch 处理。

空着意味着完全走网络，不缓存任何东西，所以你更新代码后刷新就是最新的。

3. custom_icons.js


const CUSTOM_ICONS = {
  // 'toolGift': 'icons/gift.png',
};

一张对照表：左边是元素 id，右边是图片路径。默认是空的（继续用 emoji）。


const ids = Object.keys(CUSTOM_ICONS);
if (!ids.length) return;

没配置就什么都不做，直接退出。


const host = document.getElementById(id);
const target = host.querySelector('.tool-icon, .icon');

按 id 找到那个工具格子或后台卡片，再找到里面装图标的那一层。


const img = document.createElement('img');
img.src = CUSTOM_ICONS[id];
img.className = 'custom-icon-img';
target.textContent = '';
target.appendChild(img);

把原来的 emoji 清掉，换成你的图片。图片的尺寸在 style.css 里：

工具栏 30×30、后台卡片 40×40。类名 custom-icon-img 也会继承"图标色调"的滤镜。

4. chat_sound.js


const SFX_FILES = {
  send:        { src: 'sound/send.mp3',         volume: 0.45 },
  callRequest: { src: 'sound/call-request.mp3', volume: 0.45, loop: true },
  callTone:    { src: 'sound/call-tone.mp3',    volume: 0.5 }
};

音效清单：文件路径、音量、是否循环。想调音量就改这里的数字（0~1）。


function playSfx(name) { ... }

按名字播放：第一次用到才创建 <audio>，之后重复使用；每次把进度拨回 0 再播。

chatSettings.sound === false 时直接不响（设置里的"消息与通话音效"开关）。


function playReceiveChime() { ... }

收到红包/礼物/转账时的"叮咚"，没有用文件，是用 WebAudio 现场合成的两个正弦音

（880Hz → 1174Hz），0.55 秒衰减。想换音高就改数组里的 f。


document.addEventListener('pointerdown', unlockAudio, { once: true });

手机上浏览器要求"用户先点一下"才允许出声，这一步在第一次点击时把音频解锁。

5. music_lyrics.js


const BUILTIN_LYRICS = {
  "歌名": "[00:00.31]第一句\n[00:02.74]第二句..."
};

就是把 music/ 里的 .lrc 原样打包成字符串，按歌名索引。

chat_music.js 的 lyricsFor() 读歌词的顺序是：

  1. 歌曲对象自带的 lines（听书那几首）
  2. 你通过「词」导入的歌词（存在 localStorage）
  3. BUILTIN_LYRICS（这个文件）
  4. 都没有 → 只滚歌名

所以你自己导入的歌词永远优先。想批量改内置歌词，重新生成这个文件即可（或直接在歌里点「词」重新导入）。

五、常见修改：去哪儿动手

加一个顶栏状态

router.js → STATUS_MAIN 或 STATUS_SUB 里加一行：


{ id: 'x', label: '在遛狗', color: 'st-green', weight: 3, icon: '🐕' }

weight 是相对概率，越大越常出现。

加一个互动动作

  1. data.js 的 interactLibrary 加一项 { id, name, icon }
  2. 同文件 INTERACT_REPLIES 加同名的一组回复（4 句左右）

加一套配色（3 步）

  1. data.js → PALETTES 加一行： 
    
   { id: 'mypink', name: '我的粉', group: 'plain', main: '#E58FA5', deep: '#B85F76', bg: '#FDF7F9', bubble: '#F8CBD7' }
  2. style.css → 照抄一段 html[data-palette="mypink"]:not([data-theme="dark"]) { ... }
    （--primary --primary-rgb --primary-dark --primary-light --bg-color --bubble-me --bubble-other --shadow-* 都要有）
  3. 同段里加 --icon-filter（图标色调"跟随"用的滤镜），照抄最近的配色改 hue-rotate 的角度即可
想让"我的气泡"也上色：在那个配色块里把 --bubble-me 改成颜色就行（参考 spring、peachmint）。

加礼物

chat_money.js → GIFT_ITEMS 加一行 { name, price, icon, type }。

type 要存在于 GIFT_TYPES 里；价位档位会自动按 price 归类。

加一首内置歌

  1. 把 mp3 放进 music/
  2. chat_music.js → MUSIC_LIBRARY 加： 
    
   { kind: 'song', title: '歌名', artist: '歌手', src: 'music/文件名.mp3' }
  3. 歌词：点歌单里的「词」导入 .lrc，或者发给我打包进 music_lyrics.js

改情绪的概率

chat_mood.js → moodWeights() 里的几个 return { normal, waiting, anxious }，

三个数字是相对权重。想让他更容易急，就把 anxious 调大。

改回复延迟 / 条数

设置页的滑块直接对应 chatSettings.replyDelay、replyCount 等；

真正取延迟的是 chat_core.js 的 getRandomDelay()。

改头像裁剪输出尺寸

manage_settings.js → confirmCrop() 里的 const OUT = 400;，改数字就行（会同比放大裁剪画布）。

改主题字体

style.css 最上面的 body { font-family: ... }。现在是思源宋体（Noto Serif SC）。

启动画面（加载动画）

进站时盖住"卡几秒"的全屏动画，全部写在 index.html 里，分三块：

  1. <head> 末尾的一段内联 <style> —— 背景渐变、图标漂浮/旋转（@keyframes bootFloat）、三个跳动的小点（bootDot）
  2. <body> 开头的 #bootScreen 结构：旋转爱心 + ECHO + yfueinx + 三个点
  3. </body> 前的一段内联脚本 —— 页面 load 完成后等 0.9 秒淡出；另有 9 秒兜底

爱心不是图片旋转，而是精灵动画：icons/heart-spin.png 是一张 8 连拍的精灵表

（768×96，每帧 96×96，正面→侧面→背面→侧面的 8 个角度），#bootLogo 用

background-position + steps(8) 逐帧切换；外面的 #bootHeart 负责上下弹跳。

想改的话：

  • 换图标：替换 icons/heart-spin.png，尺寸保持 768×96、每帧 96×96 横排；
    只想换静态图标就改 #bootLogo 的 background-image
  • 转速：animation: bootSpin 1.6s steps(8) infinite 里的 1.6s
  • 改文案：#bootName / #bootSub
  • 改停留时间：脚本里的 setTimeout(hide, 900)，数字是毫秒
  • 改动画幅度：@keyframes bootFloat 里的 translateY 和 rotate
  • 想加进度条：在 #bootScreen 里加一个元素，由脚本按需更新宽度
它只是"掩盖"加载，不会让启动变快。真正减少卡顿要做聊天记录分批渲染。

六、排错

改了没生效？

先 Ctrl + F5 强制刷新。GitHub Pages 有缓存，等 1~2 分钟。

没声音？

页面要先点一下（浏览器策略）。设置里确认"消息与通话音效"是开的。

录音按钮不出现？

麦克风只在 https 或 localhost 下可用，file:// 打开会被浏览器拒绝。GitHub Pages 是 https，正常。

导入的音乐丢了？

mp3 存在 IndexedDB。如果浏览器禁用了存储（无痕模式），会只剩本次有效。

桌面图标是字母？

manifest.webmanifest、icons/、sw.js、pwa.js 都要上传，并且用 https 访问。

改崩了想恢复？

F12 → Application → Local Storage → 清掉对应键；或者数据管理里"清空所有数据"。

代码建议在 GitHub 上提交一次再改，随时能回滚。
