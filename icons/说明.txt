【这个文件夹里有什么】

favicon.svg              浏览器标签页上的图标（透明底像素绿心，垂直渐变 + 深绿描边）
heart-spin.png           启动画面的旋转爱心：8 帧横排精灵表（768×96，每帧 96×96）
icon-192.png / icon-512.png     手机/电脑"添加到桌面"用的图标（角色图）
icon-maskable-512.png    安卓圆形/异形图标用的版本（留了安全边距）
apple-touch-icon.png     苹果手机加到主屏幕时用的图标（180×180）
icon-heart-*.png         同样是图标，但用像素绿心做的，备选

图标是在根目录的 manifest.webmanifest 里登记的：
  - 想换成绿心版：把 icons/icon-heart-192.png / icon-heart-512.png
    复制成 icon-192.png / icon-512.png（覆盖），再换 apple-touch-icon。
  - 想换成自己画的：按下面尺寸做好直接覆盖同名文件即可
      192×192、512×512（主图标）
      180×180（苹果）
      512×512（安卓异形，内容留出四周 10% 边距）

【界面里的小图标】

工具栏 / 后台卡片的 emoji 可以换成自己画的图：
把图放进这个文件夹，然后在根目录 custom_icons.js 里加一行：
    'toolGift': 'icons/gift.png',
id 对照写在 custom_icons.js 的注释里。
「聊天设置 → 界面配色 → 图标色调」有三档：原色 / 柔和 / 跟随配色。

【上传到 GitHub 后怎么放到桌面】

前提：仓库开着 GitHub Pages，用 https 网址打开（手机别用文件管理器直接开 html）。

● 苹果手机（Safari）
  打开网址 → 底部「分享」→ 往下找「添加到主屏幕」→ 命名 → 添加。
  之后桌面会出现图标，点开是全屏、没有浏览器地址栏。

● 安卓手机（Chrome / Edge）
  打开网址 → 右上角 ⋮ →「添加到主屏幕」或「安装应用」。

● 安卓手机（QQ 浏览器）
  QQ 浏览器没有"安装应用"，只能生成快捷方式：
  打开 https 网址 → 底部「≡」或右上角「⋯」→「添加到桌面」→ 命名 → 确定。
  如果桌面仍是字母图标，多半是网址用了 file://、或 icon-192.png 没上传；
  删掉旧图标、清一次浏览器缓存，再用 https 网址重新添加。
  想要和 App 一样的图标和全屏，还是用 Chrome / Edge 的「安装应用」。

● 电脑（Chrome / Edge）
  打开网址 → 地址栏右边会出现一个「安装」小图标（显示器加箭头），点它；
  或者 ⋮ →「保存并分享」→「安装页面为应用」。
  Windows 会建一个桌面快捷方式，Mac 会放进「应用程序」。

注意：manifest 和 icons 文件夹要一起上传，否则桌面图标会是浏览器默认的字母图标。
