Echo Yfueinx 调试手册

这些命令只在电脑浏览器控制台里使用。测试消息会真的写进聊天记录，建议先导出备份，测完长按删除。

1. 打开控制台

  1. 在电脑上打开网站；
  2. 直接按 Ctrl + Shift + J（最方便，会直接打开控制台）；
  3. 或者按 F12 打开 DevTools 后，再点「控制台 / Console」；
  4. 输入下面的命令，按回车。

先输入：

echoDebug.help()

会列出所有测试命令。

2. 让对方发消息

echoDebug.text('你在干嘛')
echoDebug.gift('一束花', 35)
echoDebug.redpacket('52.00', '测试红包')
echoDebug.transfer('520.00', '测试转账')
echoDebug.interact('抱抱')
echoDebug.interactReply('accept', '抱抱')
echoDebug.interactReply('reject', '抱抱')
echoDebug.location('在你身边(CR)')
echoDebug.musicShare('测试歌曲')
echoDebug.sharePlayable('Good Things')
echoDebug.shareLyric('Good Things')
echoDebug.musicInvite('测试歌曲')
echoDebug.choice('帮我选一下', ['A', 'B', 'C'], 1)
echoDebug.pat()

礼物价格、红包金额和位置文字可以自己改。选择卡至少两个选项。

sharePlayable('歌名') 发可播放的音乐卡；shareLyric('歌名') 从 share_songs.js 发只分享歌词的卡片，点击不会播放。歌名不填就随机。

echoDebug.interact('抱抱') 会让对方主动发一张肢体互动请求。点「接受」或「拒绝」后，约 1～2.4 秒会收到对应动作的后续回复；检查后续文案是否和动作匹配，以及约 50% 概率是否改抽主字卡库。

echoDebug.interactReply('accept', '抱抱') / interactReply('reject', '抱抱') 会绕过 50% 掷骰，直接发一条对应动作的接受/拒绝内置文案，用来检查最新文案是否已加载。

3. 测试 2G

echoDebug.network('2G')

检查：

  • 顶栏网络是否变成 2G；
  • 是否弹出「对方网络不佳」提示；
  • 发消息后回复是否明显变慢；
  • 文字回复是否出现「卡死了」这类慢网短句；
  • 多等一会儿是否出现「刚才太卡了，现在终于好了」。

测试恢复：

echoDebug.network('2G')
// 先发一条消息，再执行：
echoDebug.networkRecover()

也可以手动切回：

echoDebug.network('WiFi')
echoDebug.network('5G')

4. 测试离线

echoDebug.offline()

也可以指定离线原因：

echoDebug.offline('sleep')      // 睡觉离线
echoDebug.offline('work')       // 工作/忙碌离线
echoDebug.offline('phone_off')  // 手机没看到/关机离线

检查：

  • 状态是否显示「离线」；
  • 网络是否同步成 2G；
  • 是否弹出「对方已掉线」提示；
  • 发消息后约 3 秒是否收到带「[自动回复]」的消息。

立即补一条离线自动回复：

echoDebug.offlineAuto()

立即模拟离线回来：

echoDebug.offlineReturn()

恢复在线：

echoDebug.online()

真正的离线回来原本需要等 90～240 秒；offlineReturn() 是为了测试，会跳过等待。

5. 测试正在输入

echoDebug.typing(true)
echoDebug.typing(false)

也可以用 echoDebug.text('第二条消息') 检查：新消息到达时，「正在输入」应该自动消失。

6. 让对方随机回复

echoDebug.reply()

会走一次正常的随机回复，可能抽到字卡、礼物、音乐或拍一拍。

7. 测试内置图片卡

echoDebug.image()                 // 按当前时间、月份、星期随机发一张
echoDebug.image(22)               // 模拟晚上 22 点
echoDebug.image(7, 11)            // 模拟早上 7 点、11 月
echoDebug.image(17, 7, 6)         // 周日 17 点，偏运动/周末
echoDebug.image(17, 7, 3)         // 周三 17 点，偏工作日健身房
echoDebug.imageFile('sport_swimming_01.svg')
echoDebug.imageFile('weather_winter_sleet_01.svg')
echoDebug.images()
echoDebug.captions('sport_swimming_01.svg')
  • image(小时, 月份, 星期)：按指定条件抽一张并直接发送；小时 0～23，月份 1～12，星期 0=周日、1=周一……6=周六，不填就用当前本地时间；
  • image() 会绕过 8 分钟冷却，方便连续看效果；
  • imageFile('文件名')：不管时段/星期，强制发指定图片；第二个参数可传自定义配文，例如 echoDebug.imageFile('bath_06_night.svg', '测试配文')；
  • images()：列出所有内置图片、分类、天气、月份权重、星期权重、时段权重和配文数量；
  • captions('文件名')：列出这张图的全部配文。

建议对比：

echoDebug.image(12)        // 白天，不应该出现夜景和夜晚浴室
echoDebug.image(22)        // 晚上，不应该出现白天浴室和晚霞
echoDebug.image(17, 7, 6)  // 周日下午，运动/周末权重更高

这些消息也是真实聊天记录，测完长按删除。

8. 测试个性签名

echoDebug.signature('测试签名')
echoDebug.randomSignature()
echoDebug.signatureList()
  • signature('内容')：把当前签名改成指定文字，并立即刷新顶部签名栏；
  • randomSignature()：从签名库里随机换一条；
  • signatureList()：在控制台列出签名库和当前签名。

如果正在播放音乐、签名栏显示歌词，新签名会先记下来，等音乐停止后再显示。也可以用来测试长签名：换成 30～40 个字，检查是否先缩字、再左右滚动。

9. 测试情绪

debugMoodSwitch('sad')
debugMoodSwitch('jealous')
debugMoodSwitch('clingy')
debugMoodUpgrade()
debugMoodSample('happy', 20)
debugMoodWeights()
debugLateNightMood()

常用情绪：

calm、happy、excited、intimate、jealous、irritated、sad、anxious、anxiety、restrained、waiting、sleepy、clingy、playful、proud、thoughtful。

10. 建议的检查顺序

  1. 普通文字、礼物、红包、互动、位置、歌曲、选择卡各发一次；
  2. 点开卡片，检查是否变成「已领取 / 已拆开 / 已接受 / 已播放」；
  3. 切 2G，发几条消息，检查慢网提示、慢网短句和恢复补话；
  4. 切离线，发消息，检查 3 秒自动回复和离线回来；
  5. 用 echoDebug.image(12)、echoDebug.image(22)、echoDebug.image(17, 7, 6) 检查季节、昼夜、运动和周末权重；
  6. 用 echoDebug.interact('抱抱') 主动发互动，分别点接受和拒绝，检查后续文案；
  7. 用 echoDebug.sharePlayable() 和 echoDebug.shareLyric() 检查两种音乐卡；
  8. 检查情绪气泡是否出现、换色、升档；
  9. 刷新页面，确认刚才的测试消息还在。

12. 最近功能检查

字卡统计

统计现在只认完整字卡文本或 cardId，不再用包含匹配。刷新后如果还看到 好、我，先确认字卡库是否真的有它们：

contents.filter(c => c.type === 'text' && (c.val === '好' || c.val === '我'))

返回空数组说明字卡库没有这两张卡，统计页不应再出现。

肢体互动后续

echoDebug.interact('抱抱')

点「接受」或「拒绝」后约 1～2.4 秒，检查后续文案是否对应「抱抱」这个动作、约 50% 是否改抽主字卡库、拒绝后情绪是否偏失落/委屈/克制。六个动作的文案在 interact_result_replies.js。

两种音乐分享

echoDebug.sharePlayable('Good Things')
echoDebug.shareLyric('Good Things')

sharePlayable 是可播放音乐卡，点击调用播放器；shareLyric 只分享歌词，点击提示「希望你喜欢这首歌，希望你喜欢这句词^^✨」，长按可复制歌名/作者/歌词。可播放音乐有 8 分钟冷却，纯歌词分享不占冷却。

图片分类与权重

echoDebug.image(17, 7, 6)   // 周日 17 点，偏运动和周末
echoDebug.image(17, 7, 3)   // 周三 17 点，偏工作日健身房
echoDebug.imageFile('sport_swimming_01.svg')
echoDebug.imageFile('weather_winter_sleet_01.svg')
echoDebug.imageFile('fastfood_burger_01.svg')
echoDebug.images()

检查分类里是否有 sport、dessert、fastfood，以及月份/星期/时段权重是否正确。

13. 注意事项

  • 手机浏览器一般没有控制台，请在电脑上测；
  • 命令报 undefined 或找不到 echoDebug，先强制刷新页面（Ctrl + F5）；
  • 测试消息是真实聊天记录，不要留着当正式聊天；
  • 如果测完发现消息丢失，先不要清空数据，重新打开可能会从 IndexedDB / 最近消息缓存恢复；
  • 查看聊天记录存储：控制台输入 chatHistory.length、estimateChatHistoryBytes()、window.__historyStoreMode；清空测试记录用 await clearHistoryStore()。
